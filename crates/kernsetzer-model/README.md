# kernsetzer-model

The semantic document model of Kernsetzer, a
book-formatting app for self-publishing authors: chapters, paragraphs,
emphasis, scene breaks, tables, front and back matter, the `.kernsetzer`
project container, and typographic text normalization (smart quotes, dashes,
non-breaking spaces).

A `Book` says *what* a manuscript contains, never how it is laid out.
Importers that fill it: [kernsetzer-import](https://github.com/Kernsetzer/kernsetzer-import).

The library name is `setzer_model`.
